## 🎵 Interactive Audio & Web Audio API

The portfolio utilizes the native HTML5 **Web Audio API** to generate synthesized guitar strums and ambient chords directly in the browser without requiring external heavy audio files:
- Synthesizes acoustic harmonics and string resonance mathematically.
- Integrated mute/audio toggle accessible in the top navigation bar.
- Ambient canvas animation dynamically synchronizes with string strums.

---

## 🛠 Tech Stack & Architecture

- **Structure:** Semantic HTML5 with accessibility tags and Open Graph metadata.
- **Styling:** Modern Vanilla CSS3 utilizing CSS Custom Properties (Design Tokens), Flexbox, CSS Grid, Glassmorphism backdrop-filters, and keyframe animations.
- **Logic:** Vanilla ES6+ JavaScript handling DOM events, interactive sound synthesis, audio visualizer canvas, and smooth scrolling.
- **Icons & Fonts:** FontAwesome 6, Google Fonts (*Outfit*, *Space Grotesk*, *JetBrains Mono*, *Syne*).
- **Backend (Optional Dev Server):** Node.js lightweight static file server (`server.js`).

## 🚀 Local Setup & Running

### Option 1: Using Node.js (Recommended)
1. Ensure [Node.js](https://nodejs.org/) is installed.
2. In the terminal, navigate to the portfolio root:
   ```powershell
   cd d:\SHIYAM\portfolio
   ```
3. Start the local server:
   ```powershell
   npm start
   ```
   *(or run: `node server.js`)*
4. Open your browser and navigate to:
   ```text
   http://localhost:3000
   ```

### Option 2: Direct Browser Viewing
Simply open [index.html](file:///d:/SHIYAM/portfolio/index.html) in any modern browser (Chrome, Edge, Firefox, Brave).
